Rainie's Retail English Coach V3 Ultimate

部署方法：
1. 解压这个 zip。
2. 打开 GitHub 仓库 rainie-english。
3. 点击 Add file → Upload files。
4. 上传并覆盖这些文件：
   index.html
   manifest.json
   service-worker.js
   icon-192.png
   icon-512.png
5. 选择 Commit directly to the main branch。
6. 点击 Commit changes。
7. 等 1-3 分钟。
8. 打开 https://yucarry-art.github.io/rainie-english/

手机安装：
iPhone: Safari 打开网址 → 分享 → 添加到主屏幕。
Android: Chrome 打开网址 → 右上角菜单 → 添加到主屏幕。
