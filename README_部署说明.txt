Rainie's Retail English Lab V2

部署到 GitHub Pages：
1. 解压这个 zip。
2. 打开你的 GitHub 仓库 rainie-english。
3. 删除旧文件或直接上传覆盖同名文件。
4. 上传这些文件：
   - index.html
   - manifest.json
   - service-worker.js
   - icon-192.png
   - icon-512.png
5. 点击 Commit changes。
6. 等待 1-2 分钟。
7. 打开 https://yucarry-art.github.io/rainie-english/

手机安装：
iPhone: Safari 打开网址 → 分享 → 添加到主屏幕。
Android: Chrome 打开网址 → 右上角菜单 → 添加到主屏幕。
