Rainie's Personal English System V5

新增功能：
1. My Dictionary 菜单
2. 点击例句/句子中的英文单词
3. 弹出 Learning Card
4. 收藏到个人词库
5. 自动分类：Meeting / Presentation / Retail Design / Strategy / Small Talk / General
6. Dictionary 搜索
7. Play All 朗读收藏词
8. Dashboard 增加 Dictionary 统计
9. 完全离线，数据存在浏览器 localStorage

部署：
1. 解压 zip
2. 上传覆盖 GitHub 仓库中的：
   - index.html
   - manifest.json
   - service-worker.js
   - icon-192.png
   - icon-512.png
3. Commit directly to main
4. 等 1-3 分钟
5. 电脑 Ctrl + F5 强制刷新
6. 手机删除旧桌面图标后重新添加
