部署：
1. 解压 zip
2. 上传覆盖 GitHub 仓库全部文件，特别是新增 audio 文件夹
3. Commit directly to main
4. 等 1-3 分钟
5. 电脑 Ctrl+F5 强刷；手机删除旧桌面图标后重新添加
6. 打开 Audio Center，播放 Day 1，锁屏测试
